# 微處理機技術複習筆記

## 導言
本筆記整合了 Arduino 基礎架構、麵包板實作、序列埠偵錯以及數位/類比輸入輸出的核心技術要點。旨在協助學習者從硬體原理出發，連結底層控制邏輯與高階程式開發。

---

## 一、 Arduino 基礎與麵包板實作 (Arduino Basics & Breadboard)

### 1. 理論概念核心提煉
*   **硬體核心：** Arduino Uno 通常搭載 **ATmega328P** 微處理機（8-bit AVR RISC 架構）。
*   **記憶體架構：** 哈佛架構 (Harvard Architecture)，程式碼 (Flash) 與資料 (SRAM) 獨立存儲。
*   **GPIO 邏輯：** 每個接腳均可設定為輸入或輸出，並具備內部上拉電阻 (Internal Pull-up)。
*   **麵包板架構：**
    *   **電源軌 (Power Rails)：** 側邊紅藍線，水平連通，用於配電。
    *   **元件區 (Terminal Strips)：** 中間五孔一組，垂直連通，用於插接元件。
    *   **中斷溝 (DIP Support)：** 中間凹槽將兩側斷開，適合放置 IC 晶片。

### 2. 實作導向與範例程式碼
*   **基本架構：**
```c
void setup() {
  // 系統初始化，僅執行一次
  // 相當於暫存器的配置階段
}

void loop() {
  // 主迴圈，反覆執行
  // 系統的運行時邏輯
}
```
*   **硬體接線邏輯：**
    *   LED：[Pin] -> [電阻 (220Ω)] -> [LED 長腳 (+)] -> [LED 短腳 (-)] -> [GND]
    *   按鈕：[5V] -> [按鈕] -> [Pin] 且 [Pin] -> [電阻 (10kΩ)] -> [GND] (下拉電阻配置)

### 3. 實用性延伸與業界實務
*   **技術延伸：** 在工業環境中，為了穩定訊號，通常會使用**光隔離器 (Optoisolator)** 來隔離微處理器與高功率元件（如馬達），避免電磁干擾 (EMI)。
*   **實務場景：** 麵包板主要用於 **原型設計 (Prototyping)**。在產品量產階段，會將電路轉化為 PCB (印製電路板) 以提高耐用性與穩定性。

### 4. 潛在考點與硬體陷阱標記
*   > ⚠️ **重要考點：** 麵包板中間的凹槽是為了防止 IC 兩側接腳短路。
*   **硬體陷阱：** 絕對不要將 5V 直接接到 GND，會導致短路並可能燒毀 Arduino 板。

## 二、 序列埠偵錯技術 (Serial Debugging)

### 1. 理論概念核心提煉
*   **通訊協定：** **UART (Universal Asynchronous Receiver/Transmitter)**。
*   **異步傳輸：** 不使用共同時脈訊號，雙方必須約定相同的**鮑率 (Baud Rate)**（如 9600 bps）。
*   **偵錯原理：** 利用 Print-style debugging 將內部變數狀態透過 TX 接腳傳回電腦。

### 2. 實作導向與範例程式碼
```c
void setup() {
  Serial.begin(9600); // 初始化 UART，設定鮑率為 9600
  // 暫存器層次：設定 UBRRn (Baud Rate Register) 與 UCSRnB (控制暫存器)
}

void loop() {
  int sensorValue = 123;
  Serial.print("Sensor Data: "); // 傳送字串
  Serial.println(sensorValue);   // 傳送變數並換行
  delay(1000);
}
```

### 3. 實用性延伸與業界實務
*   **技術延伸：** **硬體序列埠 (Hardware Serial)** vs. **軟體序列埠 (SoftwareSerial)**。硬體序列埠由專門的晶片電路處理，不佔用 CPU 運算資源；軟體序列埠則模擬時序，會佔用 CPU 週期。
*   **業界實務：** 在嵌入式系統開發中，除了 Serial Print，進階開發者會使用 **JTAG/SWD 偵錯器** 進行單步執行與硬體斷點。

### 4. 潛在考點與硬體陷阱標記
*   **硬體陷阱：** 如果電腦螢幕出現亂碼，通常是因為**鮑率設定不匹配**（IDE 序列埠監控器與 `Serial.begin` 設定不同）。
*   > ⚠️ **重要考點：** `Serial.print` 是阻塞式的還是非阻塞式的？在舊版 Arduino 中它是阻塞的，會影響時序敏感的應用。

## 三、 數位輸入與輸出 (Digital I/O)

### 1. 理論概念核心提煉
*   **輸出 (Output)：** 設定為推挽式 (Push-Pull)，提供 0V (LOW) 或 5V (HIGH)。
*   **輸入 (Input)：** 感測高低電位。
*   **狀態對比表：**

| 特性 | INPUT | INPUT_PULLUP | OUTPUT |
| :--- | :--- | :--- | :--- |
| **阻抗** | 高阻抗 (Hi-Z) | 高阻抗 + 內建上拉 | 低阻抗 |
| **預設電位** | 浮動 (Floating) | 高電位 (HIGH) | 不定 |
| **用途** | 外部電路處理電位 | 接按鈕至 GND | 驅動 LED、繼電器 |

### 2. 實作導向與範例程式碼
*   **暫存器控制剖析 (ATmega328P)：**
    *   `DDRx`：方向暫存器 (Data Direction Register)。0:輸入, 1:輸出。
    *   `PORTx`：資料暫存器。輸出模式下控制電位；輸入模式下控制是否開啟上拉。
    *   `PINx`：輸入接腳暫存器。讀取物理接腳狀態。

```c
// 點亮接在第 13 腳的 LED
void setup() {
  pinMode(13, OUTPUT); // DDRB |= (1 << 5); // 將 PB5 設為輸出
}

void loop() {
  digitalWrite(13, HIGH); // PORTB |= (1 << 5); // PB5 輸出高電位
  delay(500);
  digitalWrite(13, LOW);  // PORTB &= ~(1 << 5); // PB5 輸出低電位
  delay(500);
}
```

### 3. 實用性延伸與業界實務
*   **技術延伸：** **按鈕去彈跳 (Debouncing)**。
    *   **硬體去彈跳：** 使用 RC 濾波器電路。
    *   **軟體去彈跳：** 讀取到訊號後 `delay(20)` 再次確認，或使用計時器判斷穩定時間。
*   **業界實務：** GPIO 常用於控制工業開關、指示燈或作為通訊協定的起始觸發訊號。

### 4. 潛在考點與硬體陷阱標記
*   **硬體陷阱：** 輸入接腳不可懸空 (Floating)，否則會讀到不穩定的雜訊。必須使用上拉或下拉電阻。
*   > ⚠️ **重要考點：** `digitalRead()` 讀取的是該接腳在該瞬間的電位狀態。

## 四、 類比訊號處理 (Analog I/O: ADC & PWM)

### 1. 理論概念核心提煉
*   **類比輸入 (ADC)：** 將連續電壓轉為數位數值。
    *   **解析度：** 10-bit (0-1023)。
    *   **原理：** 逐次逼近 (Successive Approximation)。
*   **類比輸出 (PWM)：** **脈寬調變 (Pulse Width Modulation)**。
    *   利用數位訊號切換的「佔空比 (Duty Cycle)」來模擬類比電壓。
    *   **解析度：** 8-bit (0-255)。

### 2. 實作導向與範例程式碼
*   **讀取可變電阻並控制 LED 亮度：**
```c
void setup() {
  pinMode(9, OUTPUT); // PWM 腳位
}

void loop() {
  int val = analogRead(A0);    // 讀取 A0 電壓 (0-1023)
  // 底層：選擇頻道 -> 啟動轉換 -> 等待標誌位 (ADSC) -> 讀取 ADCL/ADCH
  
  int brightness = map(val, 0, 1023, 0, 255); // 對應到 PWM 範圍
  analogWrite(9, brightness);  // 調整 PWM 佔空比
  // 底層：設定 Timer 的比較匹配暫存器 (OCRnx)
}
```

### 3. 實用性延伸與業界實務
*   **技術延伸：** **採樣定理 (Nyquist Criterion)**。採樣頻率必須大於訊號最高頻率的兩倍，否則會產生混疊 (Aliasing)。
*   **業界實務：** PWM 廣泛用於馬達轉速控制 (ESC)、變頻器以及 LED 調光系統。

### 4. 潛在考點與硬體陷阱標記
*   **硬體陷阱：** `analogWrite()` 並非真的輸出類比電壓（如 2.5V），而是高頻切換的 5V/0V 脈衝。若需純類比電壓，需外加低通濾波器 (Low-pass Filter)。
*   > ⚠️ **重要考點：** Arduino Uno 的 ADC 參考電壓預設為 5V，若輸入電壓超過 5V 會造成讀數飽和甚至損毀晶片。

## 🛠️ 實作速查表 (Checklist)

### GPIO 配置三步驟
1.  **確定腳位功能：** 判斷是數位(Digital)還是類比(Analog)。
2.  **設定方向：** 使用 `pinMode(pin, MODE)` 設定為 INPUT/OUTPUT。
3.  **執行動作：** 使用 `digitalWrite()` 輸出或 `digitalRead()` 輸入。

### PWM 調光配置三步驟
1.  **選擇腳位：** 必須選擇具備 `~` 符號的 PWM 專用腳位 (如 3, 5, 6, 9, 10, 11)。
2.  **初始化：** 設定該腳位為 `OUTPUT`。
3.  **控制量值：** 使用 `analogWrite(pin, 0-255)` 設定亮度/速度。

### ADC 讀取四步驟
1.  **連接硬體：** 感測器接至 A0-A5 類比輸入腳位。
2.  **呼叫指令：** `analogRead(pin)`。
3.  **數值轉換：** 將 0-1023 映射至實際單位（如電壓、溫度）。
4.  **濾波處理：** (實務建議) 多次取樣平均以減少跳動。
