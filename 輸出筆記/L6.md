# Lesson 6: 音訊基礎 (Audio Basics)

## 1. 理論概念核心提煉 (Theoretical Core)
*   **聲音原理：** 透過快速切換高低電平產生特定頻率的方波，帶動蜂鳴器震動發聲。
*   **頻率 (Frequency)：** 每秒震動次數 (Hz)，決定音高。
*   **週期 (Period)：** $T = 1/f$。
*   **蜂鳴器類型：**
    *   **主動式 (Active Buzzer)：** 內建震盪源，接電即響 (單一頻率)。
    *   **被動式 (Passive Buzzer)：** 無震盪源，需輸入 PWM 訊號或方波方可發聲 (可控制音調)。

| 音符 | 頻率 (Hz) |
| :--- | :--- |
| 中音 C (Do) | 262 |
| 中音 D (Re) | 294 |
| 中音 E (Mi) | 330 |

## 2. 實作導向與範例程式碼 (Implementation & Code)
```cpp
const int buzzerPin = 8;

void setup() {
  // 不需要特別呼叫 pinMode，tone() 會自動處理
}

void loop() {
  // tone(pin, frequency, duration)
  // 底層：使用 Timer 產生對應頻率的方波輸出
  tone(buzzerPin, 440, 500); // 播放 A4 音階 0.5 秒
  delay(1000);
  noTone(buzzerPin); // 停止發聲
}
```
*   **硬體接線：**
    *   被動蜂鳴器正極接數位腳位，負極接 GND。
    *   若音量不足，可考慮加裝電晶體驅動電路。

## 3. 實用性延伸與業界實務 (Extended Concepts)
*   **技術延伸：**
    *   **多路音訊 (Polyphony)：** Arduino 的 `tone()` 一次只能在一個腳位發聲。若要同時播放多個音調，需手動操作多個 Timer 或使用專門的合成器庫。
*   **業界實務：**
    *   **I2S 音訊介面：** 在更高階的系統 (如 ESP32 或 ARM) 中，會使用 I2S 協定搭配 DAC (數位類比轉換器) 來播放高品質音樂或語音。

## 4. 潛在考點與硬體陷阱標記 (Pitfalls)
*   **硬體陷阱：**
    *   **Timer 衝突：** `tone()` 函式會使用 Timer3 (Mega) 或 Timer2 (Uno)，這會導致同樣使用該 Timer 的 PWM 功能失效。
    *   **電流問題：** 蜂鳴器耗電較大，長時間高頻運作可能對腳位造成負荷。
*   > ⚠️ **重要考點：** 如何改變蜂鳴器的音量？(答：被動蜂鳴器可透過調整 PWM 的 Duty Cycle 或串接可變電阻；主動蜂鳴器只能透過電阻減壓)。
