# Lesson 5: 鍵盤掃描 (Keypad)

## 1. 理論概念核心提煉 (Theoretical Core)
*   **矩陣式鍵盤 (Matrix Keypad)：**
    *   將按鍵排列成行 (Row) 與列 (Column) 的交叉網格。
    *   **節省腳位：** 4x4 鍵盤僅需 8 個腳位即可控制 16 個按鍵 (若獨立連接需 16 腳位)。
*   **掃描原理：**
    1. 將所有列 (Column) 設定為輸入並開啟上拉電阻 (預設為 HIGH)。
    2. 逐一將每一行 (Row) 設定為輸出 LOW。
    3. 當某行被拉低時，檢查哪一列的狀態變為 LOW，即可定位按鍵。

## 2. 實作導向與範例程式碼 (Implementation & Code)
```cpp
const byte ROWS = 4; 
const byte COLS = 4; 
char keys[ROWS][COLS] = {
  {'1','2','3','A'},
  {'4','5','6','B'},
  {'7','8','9','C'},
  {'*','0','#','D'}
};
byte rowPins[ROWS] = {9, 8, 7, 6}; // 連接至行
byte colPins[COLS] = {5, 4, 3, 2}; // 連接至列

void setup() {
  Serial.begin(9600);
  // Keypad 函式庫會處理 pinMode 配置
}

void loop() {
  // 掃描邏輯示意：
  // 1. pinMode(rowPins[i], OUTPUT); digitalWrite(rowPins[i], LOW);
  // 2. if(digitalRead(colPins[j]) == LOW) -> 按鍵被按下
  // 3. digitalWrite(rowPins[i], HIGH); pinMode(rowPins[i], INPUT);
}
```
*   **硬體接線：**
    *   需注意鍵盤排線的順序，通常左四腳為 Row，右四腳為 Col (或反之，依型號而定)。

## 3. 實用性延伸與業界實務 (Extended Concepts)
*   **技術延伸：**
    *   **鍵盤衝撞 (Ghosting)：** 當三個以上按鍵同時按下時，可能會產生錯誤的偵測訊號。解決方案是在每個按鍵串接一個二極體 (Diode)。
*   **業界實務：**
    *   **專用晶片：** 大量按鍵應用中會使用 I2C 介面的鍵盤掃描晶片 (如 TCA8418)，減少主控端 CPU 負擔。

## 4. 潛在考點與硬體陷阱標記 (Pitfalls)
*   **硬體陷阱：**
    *   **掃描頻率過快：** 若掃描間隔太短，電荷未完全釋放可能導致誤判。
    *   **忘記開啟上拉電阻：** 若列腳位處於浮空狀態，`digitalRead()` 會一直收到雜訊。
*   > ⚠️ **重要考點：** 為何要逐行輸出 LOW 而非 HIGH？(答：搭配上拉電阻使用，輸出 LOW 可產生明顯電位差；若輸出 HIGH 則與上拉電壓相同，無法辨識)。

---
### 實作設定四步驟 Checklist
1. 定義矩陣行列數與對應符號表。
2. 配置行腳位 (Row) 為輸出，列腳位 (Col) 為輸入上拉。
3. 執行巢狀迴圈：將行設為 LOW，讀取列狀態。
4. 加入去彈跳處理或使用 `Keypad` 函式庫。
