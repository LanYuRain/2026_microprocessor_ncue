# Lesson 8: 計時器中斷 (Timer Interrupt)

## 1. 理論概念核心提煉 (Theoretical Core)
*   **計時器 (Timer)：** 硬體內部的計數器，獨立於 `loop()` 運作。
*   **Prescaler (預分頻器)：** 將系統時脈 (16MHz) 除以固定倍率 (如 8, 64, 1024)，以延長計時長度。
*   **CTC 模式 (Clear Timer on Compare Match)：** 當計數器達到預設的比較值 (`OCRn`) 時，自動歸零並觸發中斷。
*   **ISR (Interrupt Service Routine)：** 中斷發生時立即執行的函式，會暫停目前的主程式。

| 暫存器名稱 | 功能描述 |
| :--- | :--- |
| `TCCRnA/B` | 配置 Timer 模式 (如 CTC) 與 Prescaler |
| `TCNT n` | 計數器當前數值 |
| `OCR nA` | 比較值暫存器 (觸發中斷的門檻) |
| `TIMSK n` | 中斷屏蔽暫存器 (致能/禁止中斷) |

## 2. 實作導向與範例程式碼 (Implementation & Code)
```cpp
// 每秒觸發一次中斷 (1Hz)
void setup() {
  cli(); // 關閉全局中斷
  
  TCCR1A = 0; // 清除暫存器
  TCCR1B = 0;
  TCNT1  = 0; // 計數器歸零
  
  // 設定比較值 OCR1A = [16MHz / (prescaler * target frequency)] - 1
  // OCR1A = [16,000,000 / (1024 * 1)] - 1 = 15624
  OCR1A = 15624; 
  
  TCCR1B |= (1 << WGM12); // 開啟 CTC 模式
  TCCR1B |= (1 << CS12) | (1 << CS10); // 設定 1024 分頻
  TIMSK1 |= (1 << OCIE1A); // 開啟比較中斷
  
  sei(); // 開啟全局中斷
}

// 中斷服務程式
ISR(TIMER1_COMPA_vect) {
  digitalWrite(13, !digitalRead(13)); // 切換 LED 狀態
}

void loop() {
  // 主程式可自由執行其他任務，不影響計時
}
```

## 3. 實用性延伸與業界實務 (Extended Concepts)
*   **技術延伸：**
    *   **看門狗計時器 (Watchdog Timer)：** 專門用於監測系統是否當機，若程式未能在期限內重置計時器，系統將強制重啟。
*   **業界實務：**
    *   **即時作業系統 (RTOS)：** 在複雜系統中，Timer 中斷被用作作業系統的「心跳 (Tick)」，負責任務調度與環境切換。

## 4. 潛在考點與硬體陷阱標記 (Pitfalls)
*   **硬體陷阱：**
    *   **ISR 內不可使用 `delay()`：** 中斷會暫停計時系統，導致 `delay()` 鎖死。
    *   **變數共用問題：** 在 ISR 與主程式間共用的變數，必須加上 `volatile` 關鍵字，防止編譯器優化。
*   > ⚠️ **重要考點：** 為何 ISR 要盡可能簡短？(答：為了避免阻塞其他中斷與影響主程式的即時性)。

### 實作設定四步驟 Checklist

4. 致能中斷 `TIMSKn` 並寫好 `ISR` 內容。
