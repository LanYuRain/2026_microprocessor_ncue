# Lesson 2: 數位與類比輸入 (Digital & Analog Input)

## 1. 理論概念核心提煉 (Theoretical Core)
*   **數位輸入 (Digital Input)：**
    *   只有 **HIGH (5V)** 與 **LOW (0V)** 兩種狀態。
    *   **Floating (浮空)：** 腳位未接任何電壓時，狀態不確定，易受雜訊干擾。
*   **上拉/下拉電阻 (Pull-up/Pull-down)：**
    *   **Internal Pull-up：** Arduino 內建上拉電阻，將腳位預設拉至 HIGH。
*   **類比輸入 (Analog Input)：**
    *   **ADC (Analog-to-Digital Converter)：** 將連續電壓轉換為數位數值。
    *   **解析度：** ATmega328P 為 **10-bit**，數值範圍 0 ~ 1023 (對應 0 ~ 5V)。

| 特性 | 數位輸入 (Digital) | 類比輸入 (Analog) |
| :--- | :--- | :--- |
| 訊號類型 | 離散 (0, 1) | 連續 (0V ~ 5V) |
| 讀取函式 | `digitalRead()` | `analogRead()` |
| 應用 | 按鈕、開關 | 可變電阻、光敏電阻 |

## 2. 實作導向與範例程式碼 (Implementation & Code)
```cpp
const int buttonPin = 2; // 按鈕接在 D2
const int potPin = A0;   // 可變電阻接在 A0

void setup() {
  Serial.begin(9600);
  // 設定為輸入模式並開啟內建上拉電阻
  // 底層：設定 DDRD 的位元 2 為 0 (Input)，PORTD 的位元 2 為 1 (Pull-up)
  pinMode(buttonPin, INPUT_PULLUP); 
}

void loop() {
  int btnState = digitalRead(buttonPin); // 讀取按鈕 (按下時為 LOW)
  int potValue = analogRead(potPin);     // 讀取類比值 (0-1023)
  
  Serial.print("Button: "); Serial.print(btnState);
  Serial.print(" | Pot: "); Serial.println(potValue);
  delay(100);
}
```
*   **硬體接線：**
    *   **按鈕：** 一端接 D2，另一端接 **GND** (搭配 INPUT_PULLUP)。
    *   **可變電阻：** 側邊接 5V 與 GND，中間轉軸腳接 A0。

## 3. 實用性延伸與業界實務 (Extended Concepts)
*   **技術延伸：**
    *   **軟體去彈跳 (Software Debouncing)：** 按鈕按下瞬間會產生機械震盪，需透過 `delay()` 或計時邏輯避開誤觸。
*   **業界實務：**
    *   **外部中斷 (Interrupt)：** 對於即時性要求高的輸入，會使用 `attachInterrupt()` 而非在 `loop()` 中不斷輪詢 (Polling)。

## 4. 潛在考點與硬體陷阱標記 (Pitfalls)
*   **硬體陷阱：**
    *   **忘記共地：** 使用外部感測器供電時，若 GND 沒接回 Arduino，`analogRead()` 會讀到亂碼。
    *   **電壓限制：** A0 輸入不可超過 5V，否則可能燒毀微處理器。
*   > ⚠️ **重要考點：** ADC 10-bit 解析度下，每一單位代表多少電壓？(答：5V / 1024 ≈ 4.88mV)。

---
### 實作設定三步驟 Checklist
1. 確定感測器訊號類型 (Digital 或 Analog)。
2. `setup()` 中配置 `pinMode()` (類比輸入通常不需配置，但建議明確化)。
3. 使用 `analogRead()` 獲取 0-1023 的數值並進行邏輯判斷。
