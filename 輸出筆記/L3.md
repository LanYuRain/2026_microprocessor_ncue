# Lesson 3: 視覺輸出 (Visual Output)

## 1. 理論概念核心提煉 (Theoretical Core)
*   **數位輸出 (Digital Output)：** 輸出電壓為 0V 或 5V。
*   **PWM (Pulse Width Modulation, 脈寬調變)：**
    *   利用快速切換 ON/OFF 來模擬類比電壓。
    *   **Duty Cycle (佔空比)：** 一個週期內訊號為 HIGH 的時間比例。
    *   **應用：** 控制 LED 亮度、馬達轉速。
*   **RGB LED：**
    *   內含紅、綠、藍三色晶片，透過 PWM 控制不同比例可混合出各種顏色。
    *   **共陽極 (Common Anode)：** 公共端接 5V。
    *   **共陰極 (Common Cathode)：** 公共端接 GND。

## 2. 實作導向與範例程式碼 (Implementation & Code)
```cpp
const int ledPin = 9; // 支援 PWM 的腳位 (標有 ~ 符號)

void setup() {
  pinMode(ledPin, OUTPUT); // 設定為輸出
  // 底層：設定 DDRB 的位元 1 為 1 (D9 對應 PB1)
}

void loop() {
  // 呼吸燈效果
  for (int fadeValue = 0; fadeValue <= 255; fadeValue += 5) {
    // analogWrite 數值範圍 0 (0%) ~ 255 (100%)
    // 底層：配置 Timer1 的 OCR1A 暫存器
    analogWrite(ledPin, fadeValue); 
    delay(30);
  }
  for (int fadeValue = 255; fadeValue >= 0; fadeValue -= 5) {
    analogWrite(ledPin, fadeValue);
    delay(30);
  }
}
```
*   **硬體接線：**
    *   **限流電阻：** 必須接電阻防止 LED 燒毀。計算公式：$R = (V_{cc} - V_f) / I_f$。
    *   例如：$(5V - 2V) / 20mA = 150 \Omega$。

## 3. 實用性延伸與業界實務 (Extended Concepts)
*   **技術延伸：**
    *   **伽瑪校正 (Gamma Correction)：** 人眼對亮度的感知並非線性，直接線性增加 PWM 值會感覺亮度增加不均勻，實務上會使用 Lookup Table 進行校正。
*   **業界實務：**
    *   **恆流驅動 (Constant Current Drive)：** 高功率 LED 應用中，會使用專門的驅動晶片而非單純的電阻，以確保亮度穩定並延長壽命。

## 4. 潛在考點與硬體陷阱標記 (Pitfalls)
*   **硬體陷阱：**
    *   **腳位電流限制：** 單一數位腳位最大電流約 40mA (建議 20mA 以下)，驅動高電流裝置必須接電晶體 (BJT/MOSFET)。
    *   **PWM 腳位限制：** 並非所有數位腳位都支援 PWM，Uno 上僅有 3, 5, 6, 9, 10, 11。
*   > ⚠️ **重要考點：** `analogWrite(pin, 127)` 的 Duty Cycle 約為多少？(答：約 50%)。

---
### 實作設定三步驟 Checklist
1. 選擇標有 `~` 的 PWM 腳位。
2. 計算並連接合適的限流電阻。
3. 使用 `analogWrite(pin, value)` 控制輸出比例。
