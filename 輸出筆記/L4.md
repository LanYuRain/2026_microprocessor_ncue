# Lesson 4: 七段顯示器與位元運算 (7-Segment & Bitwise)

## 1. 理論概念核心提煉 (Theoretical Core)
*   **位元運算 (Bitwise Operations)：**
    *   `&` (AND)：皆為 1 則為 1。常用於 **遮罩 (Masking)**。
    *   `|` (OR)：任一為 1 則為 1。常用於 **置位 (Setting)**。
    *   `^` (XOR)：不同則為 1。常用於 **反轉 (Toggling)**。
    *   `~` (NOT)：位元反轉。
    *   `<<` / `>>` (Shift)：左移/右移。
*   **七段顯示器結構：**
    *   由 8 個 LED (a, b, c, d, e, f, g, dp) 組成。
    *   **控制邏輯：** 透過 8 位元的資料 (Byte) 控制每個線段的亮滅。

| 運算符 | 名稱 | 實務用途範例 |
| :--- | :--- | :--- |
| `a & (1 << 3)` | 檢查 | 檢查第 3 位元是否為 1 |
| `a |= (1 << 5)` | 置位 | 將第 5 位元強制設為 1 |
| `a &= ~(1 << 2)`| 清零 | 將第 2 位元強制設為 0 |

## 2. 實作導向與範例程式碼 (Implementation & Code)
```cpp
// 定義數字 0-9 的七段編碼 (共陰極示例)
// 順序：dp g f e d c b a
byte numData[] = {
  0b00111111, // 0
  0b00000110, // 1
  0b01011011, // 2
  0b01001111  // 3 ...
};

void displayDigit(byte data) {
  for(int i = 0; i < 8; i++) {
    // 使用位元運算取出每一位元的狀態
    boolean bitVal = (data >> i) & 0x01; 
    digitalWrite(i + 2, bitVal); // 假設接在 D2-D9
  }
}
```
*   **TM1638 模組：**
    *   整合了七段顯示器與掃描鍵盤。
    *   使用三線通訊 (DIO, CLK, STB)。
    *   **指令集：** 需先傳送「資料模式設定」->「位址設定」->「資料內容」。

## 3. 實用性延伸與業界實務 (Extended Concepts)
*   **技術延伸：**
    *   **多路復用 (Multiplexing)：** 為了節省腳位，多個七段顯示器會共用資料線，透過快速切換「公共端」掃描顯示，利用人眼殘留效應看到完整數字。
*   **業界實務：**
    *   **BCD-to-7Segment 解碼器：** 業界常使用 CD4511 等硬體解碼 IC，微處理器只需輸出 4-bit BCD 碼，簡化軟體負擔。

## 4. 潛在考點與硬體陷阱標記 (Pitfalls)
*   **硬體陷阱：**
    *   **共陽 vs 共陰：** 邏輯完全相反。共陽極時 `digitalWrite(LOW)` 才會亮。
    *   **位元順序：** 腳位接法若與編碼順序 (a-g) 不符，顯示會錯亂。
*   > ⚠️ **重要考點：** 如何利用位元運算將 `0b10101010` 的第 0 個位元設為 1？(答：`val | 0x01`)。

---
### 實作設定四步驟 Checklist
1. 確認七段顯示器為共陽極或共陰極。
2. 建立 0-9 的 Byte 編碼表。
3. 設定對應的 GPIO 腳位為 `OUTPUT`。
4. 使用位元位移 `>>` 與遮罩 `&` 將 Byte 輸出至各腳位。
