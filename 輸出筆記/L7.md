# Lesson 7: TFT LCD 顯示器 (ILI9341)

## 1. 理論概念核心提煉 (Theoretical Core)
*   **ILI9341 驅動晶片：** 解析度 240x320，支援 16-bit 色彩 (RGB565)。
*   **SPI 通訊協定 (Serial Peripheral Interface)：**
    *   **SCK (Clock)：** 同步時脈。
    *   **MOSI (Master Out Slave In)：** 主機發送資料至螢幕。
    *   **MISO (Master In Slave Out)：** 螢幕發送資料至主機 (較少用)。
    *   **CS (Chip Select)：** 片選，LOW 時選中裝置。
    *   **DC (Data/Command)：** 決定傳送的是命令 (LOW) 還是顯示資料 (HIGH)。
*   **RGB565 格式：** 5 bit 紅、6 bit 綠、5 bit 藍，共 16 位元。

## 2. 實作導向與範例程式碼 (Implementation & Code)
```cpp
#include "Adafruit_GFX.h"
#include "Adafruit_ILI9341.h"

#define TFT_DC 9
#define TFT_CS 10

// 建立物件
Adafruit_ILI9341 tft = Adafruit_ILI9341(TFT_CS, TFT_DC);

void setup() {
  tft.begin();
  tft.setRotation(3); // 設定螢幕方向
  tft.fillScreen(ILI9341_BLACK); // 清除螢幕
  
  tft.setCursor(0, 0);
  tft.setTextColor(ILI9341_WHITE);
  tft.setTextSize(2);
  tft.println("Hello Microprocessor!");
  
  // 畫圓形：x, y, radius, color
  tft.drawCircle(100, 100, 50, ILI9341_RED);
}

void loop() {}
```
*   **硬體接線：**
    *   **VCC:** 5V/3.3V (視模組而定)。
    *   **GND:** 接地。
    *   **CLK:** D13 (Uno 硬體 SPI)。
    *   **MOSI:** D11 (Uno 硬體 SPI)。
    *   **DC/CS:** 可自訂。

## 3. 實用性延伸與業界實務 (Extended Concepts)
*   **技術延伸：**
    *   **DMA (Direct Memory Access)：** 在高階 MCU 中，會使用 DMA 搬移顯示資料，不佔用 CPU 週期，顯著提升更新頻率 (FPS)。
*   **業界實務：**
    *   **雙緩衝 (Double Buffering)：** 為了避免螢幕閃爍，先在記憶體 (Canvas) 繪圖，完成後一次性推送到顯示器。

## 4. 潛在考點與硬體陷阱標記 (Pitfalls)
*   **硬體陷阱：**
    *   **電位邏輯死穴：** ILI9341 通常為 3.3V 邏輯，直接接 Uno 的 5V 訊號可能導致過熱或燒毀，建議使用電位轉換器 (Level Shifter)。
    *   **腳位接錯：** 尤其是 DC 與 CS 腳位，若顛倒則無法顯示任何內容。
*   > ⚠️ **重要考點：** SPI 是全雙工還是半雙工？(答：全雙工)。

### 實作設定四步驟 Checklist
1. 安裝 `Adafruit_GFX` 與 `Adafruit_ILI9341` 函式庫。
2. 嚴格對照 SPI 硬體腳位 (D11, D13) 與自訂腳位。
3. `tft.begin()` 初始化後必須先進行 `fillScreen()` 清除雜點。
4. 使用 GFX 座標系統 (左上角為 0,0) 進行繪圖。
